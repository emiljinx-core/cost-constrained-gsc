# Research report

Place the LaTeX source of the report in this folder before committing:

- `paper.tex`
- `ACM-Reference-Format.bst`
- any `.bib` or appendix files you use
- `figures/` containing `model_architecture` and the five evaluation charts
  (`chart_1_query_accuracy` ... `chart_5_runtime`, PDF or PNG)
- the compiled `paper.pdf`

These files live in your LaTeX editor project and are not part of the code
workspace, so add them here manually.
